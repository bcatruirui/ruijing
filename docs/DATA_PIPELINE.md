# 数据构建与二进制协议

`node scripts/build-data.mjs` 默认为 standard；`--profile=quick` 明确省略全球城市库但使用真实其他来源；`--reuse-cache` 复用已校验的原始文件，不刷新其原始下载时间。源文件都在项目 `data/cache/`，输出在 `data/generated/`。

大 TSV/CSV 使用 Node 流式解压与逐行转换。FFraud 当前超过 160 万条，采用每批 15,000 条的磁盘外部归并排序，而非全库装入内存；临时归一投影不保留供应商分数或 confirmations。小型 Tor/Feodo 受文件和记录上限约束，在构建内存排序。每个来源独立转换、失败隔离；无效源不发布半套分片。暂存目录完成后替换输出，清单和分片一起构建。构建不会部署，也不将查询 IP 发到任何下载 URL。

DB-IP City Lite 使用经过审查的 8 列格式：start、end、continent、countryCode、region、city、latitude、longitude。洲代码与国家代码分别验证，未知列数立即使来源不可用，不能猜测错位字段。仅有实际地址族分片时才宣称该快照支持相应 IPv4/IPv6；没有 IPv6 观察片不是 IPv6 未命中。

## RJI1 容器与格式 2 分片

头部 16 字节：0–3=`RJI1`；4=地址族 4/6；5=格式版本（当前 2，兼容 1）；6–7=记录宽度 u16LE；8–11=记录数 u32LE；12–15=字典偏移 u32LE。IPv4 记录为起点 4 字节、终点 4 字节、payload ID u32LE，共 12；IPv6 为 16+16+4，共 36。地址为大端网络字节序、区间包含两端。

格式 1 的尾部为 UTF-8 JSON payload 数组。格式 2 的尾部为 u32LE payload 数量、数量+1 个 u32LE 偏移和逐个独立 JSON payload，偏移相对于 JSON blob 起点；首个偏移为 0，末项为 blob 长度。块内重复 payload 去重，读命中项时不再解码整张字典。编码器按真实偏移开销切片，单个过大 payload 会使构建失败。

默认读取接口完整校验排序、引用与所有 payload；生产查询只有在分片长度和 SHA-256 与自有构建清单一致后，才使用格式 2 快路径，仍验证头部、偏移与命中记录。快路径不用于外部任意数据。`scripts/upgrade-data-encoding.mjs` 可对旧快照离线校验和转码，暂存成功后整体替换，不刷新上游活动日期。

按实际编码字节限制每片 128 KiB，IPv4 至多 4096 条、IPv6 至多 2048 条；必要时提前切片。来源独立，索引记录每片最小 start 和最大 end，允许不同来源或相同事件存在重叠范围。后端查所有可能相交片，不能仅看最后一条 end；最长前缀和证据融合由专用规则处理。

`manifest.json` 是完整服务器端审计清单，记录版本、构建时间、来源状态/许可/哈希、数据发布时间/下载时间/到期时间、分片地址族/范围/大小/哈希。它不应加载进访客浏览器。`prepare-runtime.mjs` 将含哈希的 metadata 紧凑编码进 Worker，在启动阶段展开，避免每个冷请求解析完整资产清单；构建、测试和部署包装器自动执行此准备步骤。仅用于区间预算的索引和实际预载 metadata 大小分别统计，不混用。

## 构建与运行门槛

运行 `node scripts/check-budget.mjs` 验证文件路径、SHA-256、分片大小、排序、18,000 文件与精简索引预算。构建完成后再次检查实际 dist；Worker 使用 Wrangler dry-run 验证 bundle 与启动。预算脚本不是 CPU 或内存压测，不代表生产已通过。

运行时最多 8 次公共资产读取、同时读取建议不超过 4，LRU 仅存最多 8 MiB 公共二进制；报告不进入共享缓存。平台 128 MB 内存由 isolate 内并发调用共享，应有界控制进行中请求和缓存。缺片、过期、格式错误、资产返回 HTML 等均使相关来源不可用。

定时更新入口 `scripts/refresh-data.mjs` 按来源节奏选择刷新内容，复用条件请求、有效原文件及未变分片。暂存快照通过分片哈希、授权标识、编码、大小和 Worker 元数据检查后替换。失败时保留可验证的旧分片和原有效期。GitHub Actions 检查核心覆盖后，仅在受保护环境启用发布时更新线上 Worker。独立 `check-published.mjs` 检查已发布核心来源的有效期，并在发布时验证版本及跨域探测。 [部署和恢复](../DEPLOYMENT.md)
