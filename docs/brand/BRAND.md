# 瑞镜 IP 原图标记

按所有者 2026-10-29 的最终选择，直接使用其已经抠好的黑白两张透明 PNG；没有重绘 R、定位镜面或轨道，没有添加底板、重新抠图或使用生成式重设计。

`source/` 在本地保存用户提供的原始素材。`scripts/extract-brand.ps1` 将最终透明 PNG 等比缩小，保留原有透明度和图案。网页使用 192 px 版本，浏览器图标使用 128 px 版本。发布使用 `public/assets/` 中的成品。浅色界面使用黑色款，深色界面使用白色款，浏览器图标跟随页面主题。

这些原图不是本项目独立绘制的 MIT 代码资产，其授权依原图权利人和所有者的实际权利而定；不因项目根目录 MIT 许可证自动变更。引用时不要宣称为重新设计的矢量标记。
